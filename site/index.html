Pagouro

This is a mirror on Quilibrium QStorage. It carries both stick zips, the signing key and the receipts that let you check any copy. Nothing here is served by a company that can change it quietly.

Both models are finished: released once, frozen, signed with the same key, timestamped on Bitcoin. If a hash below does not match the file you have, you do not have the real thing.
